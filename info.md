# Car Dashboard

Three event-driven sensors for the car dashboard: people home, vehicles home, package status. Local only.

| Sensor | State |
|---|---|
| `sensor.car_people_home` | Count home |
| `sensor.car_vehicles_home` | Count home |
| `sensor.car_package_status` | `N delivered` / `none` |

Install via HACS, then Settings → Devices & Services → Add Integration → **Car Dashboard**. No settings.
